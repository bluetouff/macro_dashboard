# Police du logo

Le header reprend le wordmark de l0g.fr avec JetBrains Mono Variable, graisse
700. Le sous-ensemble latin WOFF2 est embarqué dans le CSS pour éviter toute
requête vers un tiers et conserver la désactivation du serveur de fichiers
statiques Streamlit.

Fichier copié sans modification depuis `@fontsource-variable/jetbrains-mono`
du projet l0g. La licence SIL Open Font License 1.1 est jointe dans `OFL.txt`.
